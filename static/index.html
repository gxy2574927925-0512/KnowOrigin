使用帮助

在主界面中间对话框里，也可以直接问我「怎么使用知源」，我会当场给你使用说明。

Agent 工作台
使用说明 Esc 关闭 · 共十三节，可滚动阅读
一、快速开始（三步上手）
  1. 登录 / 注册：每个账号拥有独立的项目、资料、对话与笔记。
  2. 新建项目：左上角「＋新建项目」，输入名称；学期可自定义或留空（内置 116 门天大课程可补全，也可从共享仓库一键导入）。
  3. 上传资料并生成框架：左侧「选择项目资料」上传 PDF / Word / PPT / 图片 / TXT，或点「粘贴文本」；随后点「生成 / 更新知识框架」，等待图谱生成。
二、AI 问答（中间主对话）
  • 在输入框提问即可；粘贴题目截图可整理解题过程。
  • 输入框上方有推荐问题（基于你的知识框架生成），点「换一批」刷新，点击任意问题直接发送。
  • 选中对话中的文字会弹出浮动菜单：「💬 围绕选中提问」直接追问，「📎 加入输入框」放入输入框补充，「高亮」色板给回答重点着色（保存到笔记）。
  • 回答会标注引用来源、关联知识节点，点击「来源」可查看原文；Enter 发送、Shift+Enter 换行。
  • 输入框旁边还常驻两个入口：教学模式（切换「直接回答 / 引导模式」）与 AI 记忆（查看 AI 记住了哪些关于你的信息）。
三、项目来源（左侧面板）
  • 上传文件：支持 PDF、Word、PPT、图片、TXT，可一次多选、拖拽上传。
  • 粘贴文本：讲义、课堂笔记、题目文本直接粘贴导入。
  • 勾选对话来源：提问前可勾选部分资料，AI 只依据勾选内容回答。
  • 点来源条目可预览、重命名或删除；文件先发送到本机服务，模型密钥不会进入浏览器。
四、学习产出（右侧面板）
  • 知识框架：脑图 / 双链图谱两种视图；点节点会打开「整理助手」聚焦该节点；点「引导学习」开始苏格拉底式带学；「推荐双链」帮你建立知识点关联；节点掌握度随学习逐步提升。
  • 学习概览：查看整体学习进度、薄弱点与复习建议（复习节奏见第五节）。
  • 知识卡片：自动生成卡片，「再来一批」可换一组，翻面后可自评掌握情况（详见第五节）。
  • 小测验：可选难度（自动/简单/中等/困难）与题型（单选/多选/填空/简答/计算），交卷后自动更新掌握度。
  • 我的笔记：收藏的重要回答与高亮片段，支持颜色分类与复习。
  • 标题栏还有两个按钮：英语词汇（第六个页签，详见第十节）、导出知识库（导出为 Obsidian 可直接打开的 Markdown 库）。
五、卡片与间隔复习
  • 复习发生在卡片上：翻到背面自评「记得 / 模糊 / 忘了」，排期自动推进（FSRS），不需要单独打开复习页面。
  • 学习概览页会汇总你的复习节奏：今日已复习多少、等待复习多少、未来一周什么时候会堆成复习债，提前避开突击。
  • 每日连续学习可点亮顶部「打卡」徽章；点击徽章打开学习台历（详见第八节）。
六、整理助手与笔记（知识框架节点）
  • 点知识图谱中的节点 → 右侧弹出「整理助手」面板，可对单个节点做笔记整理。
  • 笔记采用三段式：一句话摘要 / 要点索引 / 易错或适用条件，每条结论可溯源到来源。
  • AI 生成的是建议稿，需你点「批准」后才写入知识库；「补全当前节点笔记」会生成详细的原子笔记建议稿。
  • 双链：建立节点关系时需你说明连接理由，AI 不会擅自建链，保证关联可追溯；「推荐双链 / 缺失节点」与「挖深问题」可扫描整库。
七、苏格拉底引导与教学节奏
  • 在节点上点「引导学习」，助手会先诊断你的掌握情况，再通过小问题一步步带你推导，答对前不铺开完整讲解。
  • 收敛条三个按钮：✓ 继续下一问（已答对，进入下一问）、📖 查看答案（直接给出当前这一问的答案与讲解）、⏹ 停止引导（结束本轮）。
  • 引导中选中对话或笔记预览的文字，可围绕它继续引导。
  • 教学模式（聊天输入框旁切换）：「直接回答」保持正常作答；「引导模式」先给关键概念和「去哪看」、把答案留给你，卡一次放开一级，连卡两轮才直接给结论。
八、学习台历与备考冲刺
  • 点击顶部打卡徽章打开「学习台历」三栏工作台：左栏按课程组织（每门课下挂一页速查表或学习路径）、中栏月历与当日计划、右栏考期备忘（各科考期 / 考场 / 就绪度，回标到台历格上）。
  • 在学习路径页底部点「按此路径制定冲刺计划」，选节奏（抢救 3 天 / 冲刺 7 天 / 攻坚 14 天），AI 会把每天任务写具体、写可执行，三阶段稳步推进。
  • 冲刺计划与打卡、考期备忘联动：完成情况计入台历，考期临近会自动在台历格上提醒。
九、文章阅读与文献检索（主界面顶部「文章阅读」入口）
  • 在主界面顶部点「文章阅读」进入；点右上角「返回」回到项目学习。
  • 在「我的文献」面板导入论文（PDF 或粘贴文本），自动抽取元数据、摘要与翻译；面板支持切换「我的文献 / 全球检索」，侧栏展开期刊检索与学者检索。
  • 左侧标签：AI 问答 / 目录 / 图表 / 阅读重点 / 高亮 / 笔记；顶部支持「全文翻译」「对比（2–4 篇）」。
  • 选中正文文字可高亮、提问；「切换视图」在 PDF 原页对照与文理（双语流式）排版间切换。
  • 「多文献研读」栏勾选多篇后可进综述矩阵（PRISMA 横向对比，可导出 CSV）；文献库侧栏有审稿红队（模拟顶刊审稿）；来源视图里有「研究洞察」与「节点 AI 解释」。
十、英语学习（学习产出「英语词汇」页签）
  • 词表与生词本：内置考研 / 四六级等通用词书兜底（资料导入后优先用你的资料）；生词可手动加或从语料一键采集，词条带发音朗读、例句与词汇拓展（近义词辨析 / 反义词 / 常见搭配）。
  • 语料摘录：从你自己导入的中文 / 英文资料里采词——中文资料由后端转成英文表述，每一片都带术语表，点一下就把生词带原句收进生词本。
  • 应试精读工作台：13 大外刊 + 全国统考原卷，整篇通读与段落级分析、长难句结构化、同义改写链一键入 FSRS、熟词生义雷达。
  • 刷完一轮单词可生成联结短文与助记故事，把生词串成有画面的故事，可全文朗读。
十一、AI 记忆与研究洞察
  • AI 记忆（聊天输入框旁入口）：两层槽位——全局画像（AI 推断的关于你的长期偏好）+ 项目级记忆（本项目里推断出的信息）。每格都标注是谁写的、什么时候写的、依据是什么，可改、可删、可整库清空，全程可见。
  • 研究洞察（来源视图）：AI 通读整个知识库，给出可写进综述的论断、资料间的张力、知识空白与下一步研究问题。
  • 综述矩阵（文献阅读中）：按 PRISMA 规范横向抽取多篇论文的动机、方法、数据条件、定量结果与局限，导出 CSV 做综述底稿。
  • 审稿红队（文献库侧栏）：以顶刊 / 顶会审稿人视角对你的研究做四维打分，列出致命弱点与给作者的问题。
十二、常用设置与快捷键
  • 右上角齿轮打开设置：主题（浅色/深色）、品牌主题（通用/天大）、海小棠桌宠开关、声效开关、API 设置、退出账号。
  • 「AI 透明度」小组：提示词实验室（收录 36 个 AI 任务，逐条查看实际使用的提示词，可改写并随时重置为默认）与 AI 用量（token 消耗估算，输入框旁也有入口）。
  • 快捷键：Enter 发送、Shift+Enter 换行；Esc 关闭面板 / 弹窗；左右拖动分隔条调宽度、双击恢复默认。
十三、数据与隐私
  • 项目、来源、对话、笔记、卡片与掌握度都保存在你的本机服务里，不同项目完全隔离。
  • 模型 API 密钥加密保存在你自己的本机（data/ 目录，Windows 上绑定当前登录账户）与浏览器存储里，重启服务或换浏览器都不必重填；该目录不在版本控制中，仓库里不含任何密钥，可随时在「API 设置」中更换或清空。
  • 学习产出标题栏「导出知识库」：导出为标准 Markdown + [[双链]]，不锁进任何私有格式，可直接拖进 Obsidian；导出不改变知源里的任何数据。
