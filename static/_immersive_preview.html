稳定性判据 g₁g₂

谐振腔对光的约束并非理所当然：只有当往返矩阵满足 0 ≤ g₁g₂ ≤ 1 时，腔内才存在稳定的低阶模。这个看似简单的不等式，决定了几乎所有激光器的结构取舍。

为什么需要稳定腔

光在腔内每往返一次都要经历衍射损耗与增益补偿。若 g₁g₂ 落在稳定区之外，光场每往返一次都会横向溢出，增益再高也建立不起振荡。

直觉：稳定腔像一个"光学陷阱"——镜面曲率与腔长的组合必须让光每次往返都能自再现。

临界情形

g₁g₂ = 0 与 g₁g₂ = 1 是两个临界边界：前者是共焦腔，后者是平行平面腔。平行平面腔对调准精度极其敏感，微弧度级的失准就会让损耗剧增。
