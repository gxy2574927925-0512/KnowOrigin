# data/ —— 运行时数据目录（干净默认态）

**这里默认是空的。** 克隆仓库后第一次启动，程序会自己把这个目录建好，
你不需要手动准备任何文件，也不需要往这里填任何密钥。

## 首次启动会自动生成什么

| 路径 | 内容 | 说明 |
| --- | --- | --- |
| `knoworigin.sqlite3` | 全部业务数据 | 账号、项目、资料、对话、笔记、知识框架都在这里。删掉等于重置成全新状态。 |
| `english/` | 英文词库 | 随仓库分发的那份（`data/english/*.json`）会在首次运行时就位，克隆即用。 |
| `source_files/` | 上传的原始资料 | 你导入的 PDF / Word / PPT / 图片等原件。 |
| `source_previews/` | 资料预览图 | 首次查看时懒加载生成，可随时删。 |
| `undo_trash/` | 回收站 | 删除操作的可撤销副本。 |
| `local_api_config.json` | 本机模型配置 | **只有你自己填过密钥之后才会出现**，Windows 上密钥用 DPAPI 加密、绑定当前账户。 |

## 与仓库的关系

- 本目录下的内容**不进版本控制**（见根目录 `.gitignore`：`data/*`）。
  唯一的例外是随仓库分发的 `data/english/` 词库和本说明文件。
- 仓库里**不含任何密钥、也不含任何个人数据**。密钥只有两个来源：
  你自己在 `.env` 里填，或在本应用「设置 → API 设置」里填（后者写进本目录）。
- 换机器 / 重新克隆时，把这个目录整个拷走即可带走全部数据；
  只想重置成干净默认态，直接删掉 `knoworigin.sqlite3`。

## 想改成别的目录

设置环境变量 `DATA_DIR` 指向任意路径即可（见 `.env.example`）。
